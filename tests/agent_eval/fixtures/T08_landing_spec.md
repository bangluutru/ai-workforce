# ĐẶC TẢ GIAO DIỆN HERO SECTION: WEBINAR AI WORKFORCE

- **Mục tiêu**: Xây dựng component Hero Section bằng React + TypeScript + Tailwind CSS.
- **Thành phần**:
  1. Headline: 'Tự Động Hóa Doanh Nghiệp Với 16 Nhân Sự Số'
  2. Sub-headline: 'Hệ thống tác nhân số vận hành trên Antigravity IDE - 100% Native, Zero Setup Hassle.'
  3. Form đăng ký tham dự gồm:
     - Input Email (có validation format email)
     - Input Họ và Tên (bắt buộc)
     - Nút bấm 'Nhận Vé Mời Miễn Phí' (có trạng thái loading khi submit và disable)
  4. Thông báo trạng thái: Success state và Error state.
- **Yêu cầu code**: Đầy đủ component hoàn chỉnh, type-safe TypeScript, dùng Tailwind CSS responsive, không placeholder TODO.
